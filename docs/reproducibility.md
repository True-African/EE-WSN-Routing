# Reproducibility Checklist

- Record MATLAB version and operating system.
- Record Git commit SHA for every final run.
- Use shared seeds for protocol comparisons.
- Preserve all radio-model parameters and packet size.
- State node count, field geometry, field size, sink placement, rounds, and Monte Carlo count.
- Separate calibration scenarios from confirmatory scenarios.
- Export raw histories to MAT and summaries to CSV.
- Report means, standard deviations, and 95% confidence intervals.
- Regenerate publication figures from stored raw histories.
- Verify every cited DOI and replace static Word citations with reference-manager fields before submission.
